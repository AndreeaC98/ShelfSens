# ShelfSens

## 1.Overview

Did you find yourself after a stresful moment eating something sweet like a cookie? You just wanted to make your day better, but something doesn't taste right. Oh yeah! (Checking the expiration date) These things should have been thrown in the garbage a looooong time ago. Now that you think of... what else went bad in the meantime? Nobody likes to be wasteful. Everyday you work hard to buy what you need and you feel sad to see that many things end up in the thrash.

What if there is something that can help you?

ShelfSens is your trusted app that can help one be organized and always know beforehand what is about to go bad. You will make smart decisions about what to prioritize using and reduce the waste to minimum.
